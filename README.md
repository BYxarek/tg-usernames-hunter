Консольная утилита на Python для поиска коротких, "красивых" (не набор
случайных букв) и **свободных** юзернеймов Telegram. Проверка доступности
идёт через официальный метод Telegram API `account.CheckUsername`
(библиотека Telethon) — точный ответ от самого Telegram, а не догадки по
парсингу t.me.

**[Скачать последнюю версию](https://github.com/v0idk1d/tg_username_hunter/releases/latest/download/tg_username_hunter.py)** · [Сайт проекта](https://tg-username-hunter.netlify.app)

---

## Возможности

- проверка через официальный API Telegram, а не через парсинг страниц
- только произносимые/словарные варианты — никакого случайного набора букв
- длина ника от 3 до 6 символов на выбор
- без цифр и без заглавных букв
- меню прямо в консоли — запустил и выбрал пункт
- автоустановка недостающих зависимостей через pip

## Установка

Нужен Python 3.9+.

```bash
git clone https://github.com/v0idk1d/tg_username_hunter.git
cd tg_username_hunter
pip install telethon
```

Если `telethon` не установлен — скрипт попробует поставить его сам при
первом запуске.

### Получение api_id / api_hash

1. Зайти на [my.telegram.org](https://my.telegram.org) → API development tools
2. Создать приложение, скопировать `api_id` и `api_hash`

При первом запуске Telethon один раз попросит номер телефона и код из
Telegram, дальше используется сохранённая сессия.

## Запуск

Без аргументов — интерактивное меню прямо в консоли:

```bash
python tg_username_hunter.py
```

```
┌────────────────────────────────────────┐
│  [1] Поиск по словарю (dict)            │
│  [2] Генератор слогов (syllable)        │
│  [3] Оба режима (both)                  │
│  [4] Проверить свой список (list)       │
│                                          │
│  [0] Выход                              │
└────────────────────────────────────────┘
```

Или напрямую через флаги:

```bash
export TG_API_ID=123456
export TG_API_HASH=abcdef0123456789abcdef0123456789

python tg_username_hunter.py --mode both --min-len 3 --max-len 6 --limit 200
```

| Флаг         | Описание                                             | По умолчанию |
|--------------|-------------------------------------------------------|--------------|
| `--mode`     | `dict` / `syllable` / `both` / `list`                 | `both`       |
| `--words`    | список ников через запятую (только для `--mode list`) | —            |
| `--min-len`  | минимальная длина ника (3–6)                          | `4`          |
| `--max-len`  | максимальная длина ника (3–6)                         | `6`          |
| `--limit`    | сколько кандидатов проверить за прогон                | `100`        |
| `--delay`    | пауза между запросами, сек                            | `1.0`        |
| `--output`   | файл для найденных свободных ников                    | `found.txt`  |

Найденные свободные ники пишутся в консоль и дописываются в `found.txt`.

> **О коротких никах (3–4 символа):** такие юзернеймы обычным аккаунтам
> напрямую не выдаются — они распределяются через аукцион
> [Fragment](https://fragment.com) либо резервируются для Premium-аккаунтов
> в отдельных случаях. Утилита всё равно покажет реальный статус через API.

## Как это работает

1. Генерируются кандидаты: короткие словарные слова или произносимые
   псевдослова по слоговым паттернам (CV/CVC/CVCV и т.д.)
2. Отсекаются наборы букв без гласных и с длинными сериями согласных
3. Каждый кандидат проверяется через `account.CheckUsernameRequest`
4. Свободные — сохраняются в файл и выводятся в консоль
